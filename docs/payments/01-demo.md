# 1-босқич — Local Demo: бизнес қоидалари тузатилди

Faqat `src/lib/demo/*`, `src/app/demo/*`, `src/components/demo/*` va `tests/unit/demoEngine.test.ts` o‘zgardi.
Demo маълумотлари версияси 3 га кўтарилди: эски `localStorage` маълумоти бир марта тоза бошланғич ҳолатга қайтади.

| Аудит | Нима қилинди |
|---|---|
| H1 Premium + TOP | Premium = 120 000 + «Premium» белгиси + админ ёзган имкониятлар рўйхати. TOP ҳеч қачон берилмайди; админ рўйхатига «TOP» ёзиб бўлмайди. |
| H2 Промокод лимити | Тўланмаган буюртма промокодни **банд қилади** (`promoHeld`); бекор қилинса бўшайди. Лимит оширилмайди. |
| H3 Рад этилган эълон | Эълон рад этилса тўланмаган статус буюртмалари бекор қилинади. Чек текширилаётган пайтда рад этилган бўлса, тасдиқлашда пул қайтариш **автоматик** очилади. |
| M1 Тўлов/қайтариш | `paymentStatus`: `awaiting_payment → receipt_submitted → under_review → paid / rejected / info_requested`, `cancelled`. Қайтариш алоҳида `order.refund` (`requested / refunded / declined`, сумма, сабаб, ким, қачон). Тўлов `paid` бўлиб қолади. |
| M2 Журнал | Промокод/акция ёқиш-ўчириш, демо соати, Reset ҳам ёзилади; чегара 2000 қатор. |
| M3 Карта | Ҳар бир чекда фойдаланувчига кўрсатилган карта (охирги 4 рақам, эгаси, банк) сақланади. |
| M5 Чек ҳажми | Engine ҳажм ва сақланган турни ўзи ҳам текширади. |
| M6 Фаол статус | Тасдиқланган эълон рад этилса, фаол пуллик статус учун ҳам қайтариш сўрови очилади (админ қарор қилади). |
| M8 Вкладкалар | Ҳар амалдан олдин `localStorage` қайта ўқилади. |
| M10 Чегирма қоидаси | Сервер қоидасига мослашди: акция ва промокод қўшилмайди, каттаси ишлайди, камида 1 сўм тўланади. |
| L1 Чек тури | `mime` (асл файл) ва `storedMime` (сақланган) алоҳида. |
| L2 Статус | Келажакда бошланадиган статус `scheduled` (фаол эмас). |
| L4 Қўшимча маълумот | Алоҳида `info_requested` ҳолати. |

Ўзгармаган (бизнес қарор талаб қилади): L3 (монетизация ўчиқ пайтдаги эълон бепул ҳуқуқни ишлатади), C1/C2 (demo табиати — реал ҳимоя 2–3-босқичларда серверда).

Тестлар: `npx vitest run tests/unit` — 71/71 ўтди; `tsc` — 0 хато.
